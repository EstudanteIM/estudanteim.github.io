Privacidade e Proteção de Dados

Transparência sobre como tratamos dados na plataforma ESTUDANTE.IM

Resumo rápido

  • ✔ Não comercializamos dados pessoais
  • ✔ Dados pertencem à instituição de ensino
  • ✔ Atuamos principalmente como operadora de dados
  • ✔ Uso exclusivo para fins educacionais
  • ✔ Conformidade com a LGPD (Lei nº 13.709/2018)

Como funciona nossa tecnologia

A ESTUDANTE.IM utiliza Inteligência Artificial para análise inicial das redações, combinada com validação humana por professores, garantindo consistência técnica e qualidade pedagógica no processo de correção.

Nosso papel no tratamento de dados

  • A instituição de ensino é a controladora dos dados
  • A ESTUDANTE.IM atua como operadora
  • Em casos específicos, podemos atuar como controladora (ex: contato direto)

Para que utilizamos os dados

  • Correção de redações (IA + validação humana)
  • Acompanhamento e gestão pedagógica
  • Melhoria contínua da plataforma
  • Comunicação com instituições de ensino

Segurança

Adotamos medidas técnicas e organizacionais para proteger os dados contra acessos não autorizados, uso indevido, alteração ou perda de informações.

Direitos dos titulares

  • Acesso aos dados
  • Correção de informações incompletas ou desatualizadas
  • Exclusão de dados quando aplicável
  • Revogação de consentimento
