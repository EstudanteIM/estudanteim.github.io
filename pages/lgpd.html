1. Introdução

Este Aviso de Privacidade descreve como a ESTUDANTE.IM realiza o tratamento de dados pessoais no contexto da sua plataforma educacional, em conformidade com a Lei nº 13.709/2018 (LGPD).

2. Definições

  • Controlador: pessoa natural ou jurídica responsável pelas decisões sobre o tratamento de dados
  • Operador: pessoa natural ou jurídica que realiza o tratamento de dados em nome do controlador
  • Titular: pessoa natural a quem os dados pessoais se referem
  • Dados pessoais: informações relacionadas a pessoa natural identificada ou identificável

3. Papel da ESTUDANTE.IM

A ESTUDANTE.IM atua predominantemente como operadora de dados pessoais, tratando informações em nome das instituições de ensino contratantes, que são as controladoras dos dados.

4. Dados pessoais tratados

  • Dados de identificação (nome, e-mail)
  • Dados educacionais (conteúdo produzido pelos alunos)
  • Dados de desempenho acadêmico
  • Dados de uso da plataforma

5. Finalidades do tratamento

  • Execução de serviços educacionais contratados
  • Gestão pedagógica pelas instituições de ensino
  • Melhoria contínua da plataforma
  • Suporte técnico e operacional

6. Bases legais

O tratamento de dados pessoais é realizado com base nas seguintes hipóteses legais previstas na LGPD:

  • Execução de contrato
  • Legítimo interesse
  • Cumprimento de obrigação legal ou regulatória

7. Compartilhamento de dados

Os dados pessoais poderão ser compartilhados com fornecedores e parceiros necessários para a operação da plataforma, sempre em conformidade com a legislação aplicável.

8. Armazenamento e retenção

Os dados pessoais são armazenados pelo tempo necessário para cumprimento das finalidades descritas, respeitando obrigações legais e regulatórias aplicáveis.

9. Segurança da informação

São adotadas medidas técnicas e organizacionais adequadas para proteção dos dados pessoais contra acessos não autorizados, perda, alteração ou qualquer forma de tratamento inadequado.

10. Direitos dos titulares

  • Confirmação da existência de tratamento
  • Acesso aos dados
  • Correção de dados incompletos ou desatualizados
  • Anonimização, bloqueio ou eliminação de dados
  • Portabilidade dos dados
  • Revogação de consentimento, quando aplicável

11. Alterações deste aviso

Este Aviso de Privacidade poderá ser atualizado periodicamente para refletir melhorias ou adequações legais.
